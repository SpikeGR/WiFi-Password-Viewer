
# WiFi Password Viewer V2.4

## About WiFi Password Viewer

WiFi Password Viewer is a simple, user-friendly script that allows
you to view the passwords of Wi-Fi networks currently saved on your
device. It works by retrieving the saved credentials from your system’s
network settings, making it easy to access previously connected networks.

This tool does not crack or hack any passwords, but instead reveals the
ones that are already stored on your device, providing a quick way to
retrieve forgotten Wi-Fi credentials.
